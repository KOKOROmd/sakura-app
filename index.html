さくら（個人用アシスタント）

さくらは、このアプリの所有者1人だけが使う、個人用のアシスタントです。一般には公開していません。所有者以外の人が使うことはできません。

Sakura is a personal assistant used only by its owner. It is not offered to the public.

このアプリがすること

  • 所有者自身の Gmail を読み、新着のメールを知らせたり、まとめたりします。所有者の指示があれば、ラベルを付けるなどの整理をします。
  • 所有者自身の Google カレンダーを読み、予定を知らせます。所有者の指示があれば、予定を作成・変更します。

プライバシーポリシー

最終更新：2026年11月15日

  • 扱うデータ：所有者自身の Google アカウントの、Gmail のメールと Google カレンダーの予定だけです。ほかの人のアカウントのデータは扱いません。
  • 使いみち：上に書いた機能を所有者に提供するためだけに使います。広告には使いません。
  • 保存：データと認証の情報は、所有者が管理するサーバーに保存します。
  • 第三者への提供：販売しません。機能の提供に必要な範囲で、メールや予定の内容が AI モデルの提供者に送られて処理されることがあります。それ以外の第三者には渡しません。
  • 取り消し：所有者は、Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもこのアプリのアクセスを取り消せます。
  • Google のポリシー：Google API から受け取った情報の利用と他のアプリへの転送は、「Google API サービスのユーザーデータに関するポリシー」（限定的な使用の要件を含む）に従います。
